# Janum

Janum is a numerical methods library built as a learning project. It is an ongoing attempt to implement the numerical methods I learn in code, turning mathematical ideas into practical, reusable programs.

## Current focus

The first implemented method is **Gauss–Jordan row reduction**, a method for transforming a matrix into reduced row echelon form. It can be used to solve systems of linear equations and explore the fundamentals of linear algebra computationally.

## What's next

More numerical methods will be added as I learn them. The project is intended to grow gradually, with each implementation serving both as a useful tool and as a way to deepen my understanding of numerical mathematics.

## Project status

🚧 Early development — more methods are coming soon.

## Goals

- Implement numerical methods clearly and from first principles
- Learn by translating mathematical algorithms into code
- Build a growing collection of reusable numerical tools
- Document the ideas and techniques behind each method
